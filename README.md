# sberindex-clustering

Решение задачи «Кластеризация» онлайн-конкурса СберИндекса 2026.

Строим динамическую атрибутированную сеть муниципальных образований (МО) России. Узлы сети это МО, атрибуты узлов это экономические характеристики, рёбра это экономическая близость. Сеть строится по кварталам 2023 и 2024 годов. Затем МО кластеризуются, изменения кластеров отслеживаются во времени, а кластеры описываются как типы местных экономик.

## Установка

```
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
```

## Запуск

```
python run.py download
python run.py features
```

`download` скачивает пакет данных конкурса (20 МБ) в `data/raw`. `features` собирает таблицу признаков МО по кварталам в `data/processed/features.parquet`.

Таблицы Росстата, цены по регионам и справочник МО уже лежат в `data/prepared`, их не нужно скачивать. Чтобы пересобрать их из первоисточников:

```
python run.py download --all
python run.py prepare
```

Это ещё около 5 ГБ: два архива Росстата, справочник границ МО и выгрузка цен из ЕМИСС. Архивы читаются потоком, распаковывать их не нужно. Справочник границ лежит в rar, для него нужен `bsdtar` (есть в Windows 10 и новее и в macOS, в Linux пакет `libarchive-tools`).

## Признаки

Одна строка таблицы это МО в квартале. Всего 2190 МО и 8 кварталов.

| Блок | Признак | Что это | Источник |
|---|---|---|---|
| Потребление | `share_food`, `share_marketplaces`, `share_transport`, `share_health`, `share_cafe`, `share_other` | доли категорий в безналичных тратах жителей | СберИндекс |
| Потребление | `spend_rel` | log(траты на жителя / медиана по МО в том же месяце) | СберИндекс |
| Потребление | `spend_real` | то же с поправкой на уровень цен в регионе | СберИндекс, ЕМИСС |
| Труд | `emp_agri`, `emp_mining`, `emp_manufacturing`, `emp_utilities`, `emp_construction`, `emp_trade`, `emp_transport`, `emp_services`, `emp_public` | доли работников организаций по укрупнённым разделам ОКВЭД2 | Росстат |
| Труд | `wage_rel`, `wage_real` | log(средняя зарплата / медиана по МО), с поправкой на цены и без | Росстат, ЕМИСС |
| Труд | `emp_rate` | работники организаций на одного жителя | Росстат |
| Место | `log_population`, `urban_share`, `log_density` | размер, доля городского населения, плотность | Росстат, границы МО |
| Место | `share_young`, `share_old` | доли населения моложе и старше трудоспособного возраста | Росстат |
| Место | `migration` | миграционный прирост за прошлый год на 1000 жителей | Росстат |
| Место | `market_access` | индекс доступности рынков | СберИндекс |

Разделы ОКВЭД2 укрупнены так: `agri` A, `mining` B, `manufacturing` C, `utilities` D и E, `construction` F, `trade` G, `transport` H, `services` I, J, K, L, M, N, R, S, `public` O, P, Q.

Данные Росстата идут нарастающим итогом с начала года, поэтому квартал берётся как период с января по конец квартала. Пропуски заполняются сначала значением того же МО в соседнем квартале, затем медианой по региону и типу МО. Индекс доступности рынков для 21 МО без данных берётся у ближайшего по карте МО.

## Структура

- `run.py` точка входа
- `config.yaml` источники данных, показатели Росстата, сопоставление названий регионов
- `src/download.py` загрузка исходных данных
- `src/prepare.py` подготовка таблиц Росстата, цен и справочника МО
- `src/features.py` таблица признаков
- `data/` данные, описание и лицензии в [data/README.md](data/README.md)
