# Сеть

Как строится атрибутированная сеть МО: узлы, атрибуты, правило рёбер и варианты для сравнения. Код в `src/network.py`, параметры в разделе `network` файла `config.yaml`.

Узел сети это МО в квартале. Районы Москвы и Санкт-Петербурга склеены в два узла (средние с весом по населению): это части одного города, где люди живут в одном районе, а работают и тратят в другом. В квартал берутся МО с данными о тратах за все три месяца.

Перед расчётом расстояний признаки преобразуются: доли трат через центрированный логарифм отношений (CLR, Aitchison 1986), доли занятости через квадратный корень, `emp_rate` и `market_access` через логарифм. Затем выбросы обрезаются по 1 и 99 процентилям, признаки стандартизуются по всем кварталам сразу, а каждый блок делится на корень из числа своих признаков, чтобы блоки давали равный вклад.

Атрибуты узла x_i это все три блока. Ребро строится по сходству потребления: пусть s_ij это косинусное сходство векторов блока «Потребление» МО i и j, N_k(i) это k МО с наибольшим s_ij. Ребро (i, j) есть, если j входит в N_k(i) или i входит в N_k(j), его вес max(s_ij, 0). По умолчанию k = 10.

Для сравнения строятся другие правила: k = 5 и 20, взаимные k ближайших соседей, порог по сходству с той же средней степенью, сходство по всем признакам, корреляция остатков месячного роста трат за 12 месяцев, близость по автодорогам exp(-d_ij / d0) и гибрид «похожее потребление и рядом». Расстояния по дорогам берутся из пакета данных конкурса, для МО без дорог используется расстояние по прямой, умноженное на медианный коэффициент извилистости 1.27.
