# Сеть

Как строится атрибутированная сеть МО, то есть узлы, атрибуты, правило рёбер и варианты для сравнения. Код в `src/network.py`, параметры в разделе `network` файла `config.yaml`.

Узел сети это МО в окне скользящего года (12 месяцев с концом в квартале, см. [features.md](features.md)), таблица задаётся параметром `network.features`. Районы Москвы и Санкт-Петербурга склеены в два узла. Это части одного города, где люди живут в одном районе, а работают и тратят в другом. Признаки города это средние с весом по населению по районам, у которых есть траты за все месяцы окна. Город входит в окно, если на такие районы приходится не меньше `network.city_coverage` его населения. В каждом окне у двух городов не хватает данных только у нескольких малых поселений, это меньше 0.1% населения. Остальные МО берутся в окно, если у них есть данные о тратах за все месяцы окна.

Перед расчётом расстояний признаки преобразуются. Доли трат переводятся в центрированный логарифм отношений (CLR, Aitchison 1986), доли занятости через квадратный корень, `emp_rate` и `market_access` через логарифм. Затем выбросы обрезаются по 1 и 99 процентилям, признаки стандартизуются по всем кварталам сразу, а каждый блок делится на корень из числа своих признаков, чтобы блоки давали равный вклад.

Атрибуты узла x_i это все три блока. Ребро строится по сходству потребления. Пусть s_ij это косинусное сходство векторов блока «Потребление» МО i и j, N_k(i) это k МО с наибольшим s_ij. Ребро (i, j) есть, если j входит в N_k(i) или i входит в N_k(j), его вес max(s_ij, 0). По умолчанию k = 10.

Для сравнения строятся другие правила. Это k = 5 и 20, взаимные k ближайших соседей, порог по сходству с той же средней степенью, сходство по всем признакам, близость по автодорогам exp(-d_ij / d0), гибрид «похожее потребление и рядом» и три правила по месячным рядам трат. Расстояния по дорогам берутся из пакета данных конкурса, для МО без дорог используется расстояние по прямой, умноженное на медианный коэффициент извилистости 1.27. Правила по дорогам, гибрид, сходство по всем признакам и правила по месячным рядам тоже берут k = 10 ближайших по своему сходству.

Правила по месячным рядам используют 12 месяцев окна. Общая для страны сезонность снимается вычитанием медианы по всем МО в каждом месяце, пропуски заменяются нулём, каждый ряд z-нормируется.
- **Корреляция роста.** Ряд g_t^i это разность логарифмов трат МО i в соседних месяцах минус медиана этой разности по МО. Сходство это корреляция Пирсона рядов g^i и g^j.
- **Лаговая корреляция.** Сходство это наибольшая по сдвигам l от -L до L корреляция сумма_t g_{t+l}^i g_t^j / (T - l), где T длина ряда, L = `network.max_lag` (3 месяца). Сдвиг l > 0 значит, что j опережает i на l месяцев. Так проверяется, есть ли МО, которые повторяют динамику других с задержкой.
- **DTW** (dynamic time warping, Sakoe, Chiba 1978). Ряд y_t^i это логарифм трат МО i в месяце t минус медиана по МО. Расстояние d_ij это корень из наименьшей суммы (y_a^i - y_b^j)^2 по монотонным путям, которые выравнивают месяцы a и b с |a - b| не больше B = `network.dtw_band` (полоса Сакоэ-Чиба, 2 месяца). DTW считает похожими ряды одной формы, сдвинутые и растянутые во времени. Сходство exp(-d_ij / медиана d).

Правила сравниваются на окне 2024 года по устройству графа (изолированные МО, компоненты, кластеризация, доля рёбер внутри региона, длина рёбер) и по сообществам Louvain на нём (модулярность, NMI с регионами). Независимая проверка это Moran's I (Moran 1950) признаков труда и места, которые не входят в рёбра ни одного правила, кроме сходства по всем признакам. Для признака z с центрированными значениями I = (n / S0) сумма_ij w'_ij z_i z_j / сумма_i z_i^2, где w' это веса рёбер, нормированные по строкам, а S0 их сумма. Высокий Moran's I значит, что правило связывает МО с похожей местной экономикой. В таблицу идут медианы по блокам «Труд» и «Место» и отдельно зарплата. Для каждого правила считается, насколько совпадают рёбра (Jaccard) и сообщества (ARI) соседних окон.

Правила по месячным рядам дают худшие сети. Moran's I труда и места 0.23 и 0.28 у корреляции роста, 0.13 и 0.19 у DTW, 0.04 и 0.07 у лаговой корреляции против 0.30 и 0.51 у kNN по потреблению. Лаговая корреляция у 61% рёбер выбирает наибольший разрешённый сдвиг 3 месяца и только у 12% нулевой. Рёбра соседних окон, у которых 9 из 12 месяцев общие, совпадают у неё на 0.05-0.08 по Jaccard, у DTW на 0.08-0.11, у kNN по потреблению на 0.53-0.58. Это подгонка под шум коротких рядов, поэтому время учитывается окнами скользящего года и многослойной сетью (см. [dynamics.md](dynamics.md)), а не рёбрами.

Результаты лежат в `results`.
- `edges.csv` содержит показатели каждого правила на окне 2024 года.
- `edges_jaccard.csv` и `edges_partition_ari.csv` показывают, насколько совпадают рёбра (Jaccard) и сообщества Louvain (ARI) разных правил.
- `edges_over_time.csv` показывает то же между соседними окнами для каждого правила.
- `edges_lags.csv` содержит распределение сдвигов на рёбрах лаговой корреляции.
