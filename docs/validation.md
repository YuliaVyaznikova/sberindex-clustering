# Проверка результатов

Шаг `python run.py validate` проверяет итоговые типы с разных сторон. Он смотрит, какие признаки определяют типы, как типы лежат на сети, согласны ли с ними другие методы, насколько они устойчивы и как модель выглядит среди всех методов по шести индексам критериев. Шагу нужны результаты `compare`, `track` и `robustness`. Код в `src/validate.py`, параметры в разделе `validate` файла `config.yaml`. Таблицы пишутся в `results/validate_*.csv`, рисунки в `results/figures`. Все проверки идут на окне `compare.period` (скользящий год 2024).

## Признаки

- **Ablation по блокам.** Модель в одном окне (совместная спектральная кластеризация с уточнением, параметры `model`) строится без одного блока признаков, только на потреблении или с рёбрами по всем признакам. Для каждого варианта считается ARI с моделью на всех блоках. Файл `validate_blocks.csv`.
- **Важность признаков.** Random forest (Breiman 2001, 400 деревьев) по 25 исходным признакам предсказывает итоговый тип. Accuracy на 5-fold кросс-валидации показывает, насколько типы выражаются через исходные признаки, а permutation importance показывает, какие признаки нужнее всего. Важность занижена у признаков, которые сильно коррелируют с другими. Файл `validate_importance.csv`.

## Сеть

- **Описание графа потребления.** Считаются степени, связность, коэффициент кластеризации и средняя длина пути (по 400 случайным стартовым узлам). Для сравнения те же величины считаются на графе, где рёбра перемешаны с сохранением степеней узлов (Maslov, Sneppen 2002), по 5 перемешиваниям. Ещё считаются small-world index sigma = (C / C_перемешанный) / (L / L_перемешанный) (Humphries, Gurney 2008) и degree assortativity. Файл `validate_network.csv`.
- **Mixing matrix типов** показывает, какая доля веса рёбер МО каждого типа ведёт к МО каждого типа. Доля веса рёбер внутри типов сравнивается с ожидаемой при случайном соединении с теми же суммарными весами узлов, то же делается для регионов. Файлы `validate_network.csv`, `validate_mixing.csv`.
- **Moran's I** (Moran 1950) считается для каждого признака на графе потребления с построчной нормировкой весов, значимость проверяется permutation test на 499 перестановках. Он показывает, какие признаки согласованы с сетью, то есть у каких признаков соседи по сети похожи. Признаки потребления согласованы с графом по построению, поэтому содержательный вопрос в признаках труда и места. Файл `validate_moran.csv`, рисунок `network_structure.png`.

## Мосты между типами

Participation coefficient (Guimerà, Amaral 2005) P_i = 1 - сумма по типам t (s_it / s_i)^2, где s_it это вес рёбер МО i к МО типа t, s_i это сумма весов его рёбер. P = 0, если все связи МО ведут внутрь его типа, и P растёт, если связи распределены между типами. МО с P больше `validate.bridge_participation` (0.62, порог авторов для connector nodes) считаются мостами между типами. Для каждого МО записаны тип, P, доля веса рёбер внутри своего типа, главный другой тип и уверенность из бутстрепа в шаге `robustness`. Файл `validate_bridges.csv`.

## Уверенность и смены типа

Это проверка согласованности. Она смотрит, отличают ли уверенность из бутстрепа в первом окне, participation coefficient и доля рёбер внутри своего типа те МО, которые сменили тип к последнему окну. Считаются AUC, тест Манна-Уитни и доля сменивших тип по интервалам уверенности. Это не прогноз, потому что многослойная модель строится по всем окнам сразу и видела последнее окно. Файлы `validate_changes.csv`, `validate_changes_by_confidence.csv`.

## Согласие методов

Все методы сравнения строятся с k = `model.k` на одном окне. Это k-means, Уорд, GMM, спектральная по графу, Louvain и Leiden (с первым значением resolution, которое даёт k сообществ) и все совместные методы при каждом alpha из `validate.consensus_alphas`, у всех одинаковое число вариантов. К ним добавляются итоговые типы (`multilayer`). По этим разбиениям считаются три вещи.
- Попарный ARI и средний ARI каждого разбиения со всеми остальными. Разбиение с наибольшим средним это медоид ансамбля.
- Consensus clustering, то есть спектральная кластеризация co-association matrix, где элемент (i, j) это доля методов, поместивших МО i и j в один кластер (Fred, Jain 2005). Итоговые типы в консенсус не входят.
- Согласие методов для каждого МО. Это средняя доля методов, которые поместили его в один кластер с остальными МО его типа.

Состав ансамбля влияет на консенсус. Если в ансамбле много вариантов одного семейства, консенсус тянется к нему, поэтому у каждого совместного метода одинаковое число вариантов. Файлы `validate_methods_ari.csv`, `validate_consensus.csv`, `validate_support.csv`, рисунок `methods_ari.png`.

## Устойчивость

Устойчивость считается как в `compare` (ARI между разбиением всех МО и разбиениями 90% МО), но на `validate.stability_runs` подвыборках, одних и тех же для всех методов и всех k. Для k-means и модели (совместной спектральной кластеризации с уточнением) считается кривая по k из `validate.stability_ks`. Если при каком-то k разбиение воспроизводится лучше, чем при соседних, это указывает на естественное число групп (Ben-Hur et al. 2002, von Luxburg 2010). Для остальных методов устойчивость считается при k модели в лучшей конфигурации каждого метода по threshold aggregation (см. раздел о ранжировании методов). Так проверяется, устойчивы ли лидеры по индексам. Записаны среднее, разброс, 5 и 95 процентили и доля подвыборок с ARI не ниже 0.85. Файл `validate_stability.csv`, рисунок `stability_curve.png`.

## Внешняя проверка по показателям Росстата

Типы проверяются для всей страны показателями, которых не было среди признаков. Это пять показателей из базы данных показателей муниципальных образований Росстата (раздел `external` файла `config.yaml`, таблицы `data/prepared/external_*.csv.gz`, см. [data.md](data.md)).
- Оборот розничной торговли организаций на жителя, 2024 год.
- Оборот общественного питания организаций на жителя, 2024 год.
- Ввод жилья, кв. м на 1000 жителей, 2024 год (2023 год, если за 2024 нет).
- Инвестиции организаций в основной капитал на жителя, 2023 год.
- Число мест в коллективных средствах размещения на 1000 жителей, 2024 год (2023 год, если за 2024 нет).

Оборот, ввод жилья и инвестиции даны без субъектов малого предпринимательства. Значения делятся на население МО в окне. Для каждого показателя считаются две вещи.
- Тест Краскела-Уоллиса проверяет, различаются ли распределения показателя между итоговыми типами.
- Eta squared по H (Tomczak, Tomczak 2014) eta2_H = (H - k + 1) / (n - k) это доля разброса рангов показателя, объяснённая разбиением, с поправкой на число групп k. Она считается для итоговых типов, для разбиения каждого метода из раздела «Согласие методов» и для деления на регионы (77 групп).

Файлы `validate_external.csv`, `validate_external_medians.csv` (медианы показателей по типам).

## Сравнение с «Четырьмя Россиями»

Итоговые типы сопоставляются с известной схемой Н. Зубаревич (2011). В ней Россия 1 это крупные города, Россия 2 средние промышленные города, Россия 3 село и малые города, Россия 4 республики Северного Кавказа и юга Сибири. Схема переводится в правило для МО (раздел `four_russias` файла `config.yaml`). Россия 4 это МО республик Алтай, Дагестан, Ингушетия, Кабардино-Балкария, Карачаево-Черкесия, Северная Осетия, Тыва и Чечня (коды регионов в `four_russias.fourth_region_codes`). Остальные городские округа и города федерального значения от 250 тыс. жителей относятся к России 1, от 20 до 250 тыс. к России 2. Все остальные МО относятся к России 3. Это приближение, потому что берётся население МО, а не города, и в муниципальных округах бывают средние города. Считаются таблица сопряжённости (число МО и население), V Крамера и ARI. Файлы `validate_four_russias.csv`, `validate_four_russias_population.csv`.

## Ранжирование методов по шести индексам

Все конфигурации из `results/methods.csv` с k = `model.k` (каждый метод, а у совместных методов каждое alpha) оцениваются по шести индексам из критериев конкурса. Это SW, CH, S_Dbw, AVI, AVU и MQ (см. [metrics.md](metrics.md)). По каждому индексу конфигурация получает оценку 1, 2 или 3, то есть попадает в лучшую, среднюю или худшую треть всех конфигураций. Конфигурации упорядочиваются по threshold aggregation (Aleskerov et al. 2007). Лучше та, у которой меньше худших оценок, а при равенстве та, у которой меньше средних. Это некомпенсаторное правило, и провал по одному индексу нельзя покрыть рекордом по другому. Для сравнения приводятся компенсаторная сумма рангов по шести индексам (Borda count), доля веса рёбер внутри кластеров и устойчивость из `compare`. Файл `validate_ranking.csv`. В `validate_ranking_methods.csv` записаны лучшая конфигурация каждого метода и её устойчивость на подвыборках этого шага (`stability_runs`). Индексы не учитывают устойчивость, поэтому конфигурация может быть лучшей по индексам и при этом плохо воспроизводиться на части МО.

## Вес графа в уточнении

Вес графа w в шаге уточнения выбирается по таблице `validate_refinement.csv`. Для каждого w из `validate.refine_weights` и для модели без уточнения в ней записаны шесть индексов, доля веса рёбер внутри типов, оценки по третям и место по threshold aggregation при добавлении этой конфигурации к `results/methods.csv`, устойчивость на подвыборках этого шага и ARI с разбиением без уточнения и с моделью.

Правило выбора такое. Берётся наибольший вес графа, при котором у разбиения нет худших третей, а устойчивость не ниже, чем без уточнения. Так модель сохраняет как можно больше структуры сети и при этом не проваливается ни по одному индексу.

| w | худших третей | средних третей | место | MQ | доля рёбер внутри типов | устойчивость |
|---|---|---|---|---|---|---|
| 0 | 0 | 3 | 1 | 0.48 | 71% | 0.896 |
| 0.3 | 0 | 2 | 1 | 0.49 | 73% | 0.893 |
| 0.5 | 0 | 3 | 1 | 0.51 | 75% | 0.894 |
| 0.6 | 0 | 3 | 1 | 0.52 | 76% | 0.894 |
| 0.7 | 0 | 3 | 1 | 0.53 | 77% | 0.896 |
| 0.8 | 1 | 2 | 13 | 0.56 | 80% | 0.899 |
| 0.9 | 1 | 2 | 13 | 0.58 | 83% | 0.884 |
| 1 | 2 | 0 | 32 | 0.63 | 88% | 0.861 |
| без уточнения | 1 | 3 | 18 | 0.57 | 81% | 0.892 |

- При w от 0 до 0.7 худших третей нет, место первое, устойчивость 0.893-0.896. С ростом w растут MQ и доля рёбер внутри типов, а при w = 0.8 появляется худшая треть по S_Dbw, поэтому выбран w = 0.7.
- У w = 0.3 средних третей две, но это эффект порога, а не настоящее преимущество. S_Dbw у него 0.6968 при границе лучшей трети 0.6970.
- Разбиения при w от 0.5 до 0.8 почти совпадают с моделью (ARI 0.94-0.96), поэтому точное значение w мало влияет на типы.
- Независимая проверка на синтетике с истинными типами из разных методов подтверждает выбор (см. раздел «Истинные типы из других методов» в [synthetic.md](synthetic.md)). В сценарии `calibrated` w = 0.7 лучший по худшему случаю, в `pairs_by_spending` лучший w = 0.5, а w = 0.7 почти не уступает.
