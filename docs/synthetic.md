# Синтетические данные с известными типами

Внутренние метрики не говорят, насколько разбиение близко к правильному, поэтому методы дополнительно проверяются на синтетических данных, где правильные типы известны. Шаг `python run.py synthetic`, код в `src/synthetic.py`, параметры в разделе `synthetic` файла `config.yaml`. Шагу нужны итоговые типы из `track`.

## Как строятся данные

Синтетические МО собираются из реальных, чтобы данные были похожи на настоящие.
- Центры типов и их размеры берутся из итоговых типов в окне `compare.period`.
- Разброс внутри типа это отклонения реальных МО от центра своего типа. Они раздаются синтетическим МО случайно, без связи с их типом.
- Граф строится так же, как в SPECTRA. Это k ближайших соседей по косинусному сходству блока «Потребление» (`network.k`) и граф ближайших соседей по всем признакам.

Сценарии устроены так.
- `calibrated` строится как описано выше.
- В `pairs_by_spending` типы разбиты на пары. Внутри пары блоки «Труд» и «Место» одинаковые, и типы различаются только тратами.
- В `spending_only` блоки «Труд» и «Место» не несут информации о типе.
- В `noisier` разброс внутри типов в `synthetic.noise` раз больше.
- В `independent_graph` разброс в `synthetic.noise` раз больше, а граф не строится из признаков и несёт свой сигнал. Это planted partition с той же средней степенью и долей рёбер внутри типа `synthetic.inside_share`.
- В `no_spending` блок «Потребление» не несёт информации о типе, поэтому граф потребления становится шумом.

Каждый сценарий повторяется `synthetic.repeats` раз с разными seed.

## Что считается

Все методы сравнения строятся с истинным числом типов. Это k-means, Уорд, GMM, спектральная кластеризация по графу, Louvain и Leiden, совместные методы при alpha SPECTRA (среди них совместная спектральная кластеризация без уточнения) и SPECTRA при каждом alpha из `synthetic.alphas`. Для каждого разбиения считаются ARI с истинными типами и все метрики из [metrics.md](metrics.md).
- `results/synthetic.csv` содержит все разбиения во всех наборах.
- `results/synthetic_ari.csv` содержит средний ARI каждого метода в каждом сценарии.
- `results/synthetic_indices.csv` содержит корреляцию Спирмена каждой метрики с ARI по методам внутри набора, среднюю по наборам. Она показывает, какие метрики в каком режиме выбирают разбиение, близкое к правильному.
- Рисунок `synthetic_ari.png`.

## Результаты

Средний ARI с истинными типами по 5 наборам, совместные методы при alpha 0.3 (alpha SPECTRA), KEFRiN и CANUS с евклидовым расстоянием. SPECTRA это совместная спектральная кластеризация с уточнением. SW и MQ истинного разбиения показывают, на что похож сценарий. Для сравнения, на реальных данных SW разбиения k-means 0.115, SPECTRA 0.125.

|---|---|---|---|---|---|---|---|---|---|---|

| `spending_only` | 0.062 | 0.53 | 0.30 | 0.33 | 0.30 | 0.29 | **0.45** | 0.44 | 0.36 | 0.41 |
| `noisier` | 0.043 | 0.32 | 0.31 | **0.31** | 0.25 | 0.24 | 0.21 | 0.20 | 0.25 | 0.29 |
| `independent_graph` | 0.044 | 0.56 | 0.31 | 0.33 | 0.29 | 0.33 | **0.99** | 0.88 | 0.49 | 0.45 |

- На данных, похожих на реальные, SPECTRA точнее остальных методов в каждом из 5 наборов. У неё ARI 0.67, у k-means 0.59, у KEFRiN 0.57. Шаг уточнения добавляет к совместной спектральной кластеризации 0.05 (без него 0.62), тоже в каждом наборе. Если три пары типов различаются только тратами, разрыв больше, 0.77 против 0.65 у k-means. Лучший вес графа на первом шаге 0.3 и 0.5 (0.67 и 0.66), при alpha 0 получается 0.60, при alpha 1 0.55.
- Если типы различаются только тратами, весь сигнал в графе потребления, и методы по графу лучше (0.44-0.46). Модель находится между ними и методами по признакам (0.41).
- Если граф несёт сильный собственный сигнал, а признаки шумные, alpha 0.3 для него мал. ARI получается 0.45, а при alpha 0.7 0.63. Уточнение здесь немного снижает ARI (без него 0.49), потому что шаг уточнения смотрит и на признаки, а они в этом сценарии сильно зашумлены.
- Если граф не связан с типами (`no_spending`), совместные методы почти не находят типы. У SPECTRA ARI 0.16, без уточнения 0.04, у методов по признакам 0.39. Такой режим распознаётся и без истинных типов, по MQ разбиения k-means на графе. В этом сценарии он 0.05, в `calibrated` 0.50, а на реальных данных 0.43, то есть реальные данные далеки от режима, где граф бесполезен.

## Истинные типы из других методов

В сценариях выше истинные типы взяты из решения SPECTRA, поэтому синтетика может давать ей преимущество. Чтобы это проверить, сценарии из `synthetic.truth_scenarios` строятся ещё и на типах других методов, их список в `synthetic.truths`. Для k-means и спектральной кластеризации по графу центры, размеры и разброс типов считаются по их разбиению того же окна, а генератор данных остаётся тем же. На каждом наборе запускаются методы по признакам, спектральная по графу, KEFRiN и совместная спектральная без уточнения при alpha SPECTRA и SPECTRA при каждом весе графа в уточнении из `validate.refine_weights`. Результаты в `results/synthetic_truths.csv` и `results/synthetic_truths_ari.csv`.

Средний ARI по 5 наборам в сценарии `calibrated`. Столбцы показывают, из чьих типов построены данные, в последнем столбце худший из трёх случаев.

| Метод | типы SPECTRA | типы k-means | типы спектральной по графу | худший случай |
|---|---|---|---|---|
| k-means | 0.59 | **0.73** | 0.43 | 0.43 |
| KEFRiN, евклид | 0.57 | 0.73 | 0.46 | 0.46 |
| KEFRiN, косинус | 0.52 | 0.56 | 0.52 | 0.52 |
| GMM | 0.50 | 0.50 | 0.33 | 0.33 |
| Уорд | 0.51 | 0.48 | 0.32 | 0.32 |
| спектральная по графу | 0.45 | 0.33 | **0.63** | 0.33 |
| совместная спектральная без уточнения | 0.62 | 0.47 | 0.51 | 0.47 |
| SPECTRA | **0.67** | 0.55 | 0.53 | **0.53** |

То же для сценария `pairs_by_spending`.

| Метод | типы SPECTRA | типы k-means | типы спектральной по графу | худший случай |
|---|---|---|---|---|
| k-means | 0.65 | **0.51** | 0.29 | 0.29 |
| KEFRiN, евклид | 0.65 | 0.50 | 0.32 | 0.32 |
| KEFRiN, косинус | 0.62 | 0.45 | 0.45 | 0.45 |
| GMM | 0.41 | 0.36 | 0.28 | 0.28 |
| Уорд | 0.55 | 0.39 | 0.29 | 0.29 |
| спектральная по графу | 0.43 | 0.32 | **0.65** | 0.32 |
| совместная спектральная без уточнения | 0.73 | 0.43 | 0.53 | 0.43 |
| SPECTRA | **0.77** | 0.48 | 0.57 | **0.48** |

- На данных из типов какого-то метода лучше всех этот метод или близкий к нему. На типах k-means лучше всех k-means и евклидов KEFRiN (0.73 и 0.73), на типах спектральной по графу сама спектральная (0.63), на типах SPECTRA сама SPECTRA (0.67).
- Когда данные построены из типов другого метода, SPECTRA уступает только этому методу и близким к нему и обгоняет остальные, поэтому её худший случай самый высокий. В `calibrated` он равен 0.53, у следующего метода 0.52, у k-means 0.43. В `pairs_by_spending` 0.48 против 0.45 у следующего метода.
- Значит, SPECTRA надёжнее остальных методов, когда неизвестно, какое разбиение ближе к реальности, а на реальных данных это неизвестно всегда. Выигрыш на данных из собственных типов есть у каждого метода, поэтому честнее сравнивать методы по худшему случаю, и по нему модель первая.
- Тот же худший случай помогает выбрать вес графа в уточнении. В `calibrated` он наибольший при w = 0.8 (0.53), в `pairs_by_spending` при w = 0.0 (0.50). В среднем по двум сценариям наибольший худший случай даёт w = 0.7 (0.51), а веса от 0.6 до 0.8 почти равны. Малый вес лучше на типах k-means, большой на типах спектральной по графу.
