# Устойчивость результатов

Насколько итоговые типы и их динамика зависят от параметров модели и от состава МО. Код в `src/robustness.py`, запуск `python run.py robustness` (около 50 минут), параметры в разделе `robustness` файла `config.yaml`.

## Чувствительность к параметрам

Многослойная сеть (см. [dynamics.md](dynamics.md)) пересчитывается на сетке параметров: число соседей в графе (`grid.graph_k`), вес графа alpha, число типов k и сила связи между окнами. Для каждой конфигурации считаются:
- доля МО, сменивших тип между первым и последним окном;
- ARI с основным решением в первом и последнем окне;
- средние по окнам SW в пространстве признаков и MQ на графе потребления.

Результат в `results/sensitivity.csv`.

## Бутстреп по МО

Модель пересчитывается `runs` раз, каждый раз на случайной доле `share` всех МО (одной и той же во всех окнах). Типы каждого прогона сопоставляются с основным решением венгерским алгоритмом по числу общих МО. Результаты:
- `results/confidence.csv`: для каждого МО и окна доля прогонов, в которых МО попал в свой основной тип (уверенность принадлежности);
- `results/transition_robustness.csv`: для каждого МО доля прогонов, в которых он сменил тип между первым и последним окном. Переход, который повторяется в большинстве прогонов, считается надёжным.
